# MSAI6320 Unit 4 Lab: Logistic Regression and Text Classification

Airline customer-message triage (Twitter US Airline Sentiment) for MSAI6320 NLP, Birzeit University.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook MSAI6320_LogReg_and_TextClassification.ipynb
```

The notebook reads its data from `Data/`. See `Data/README.md` for the dataset license (CC BY-NC-SA 4.0).
